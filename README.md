# Project Norm

An artificial-life playground inspired by [_Creatures 2_ (1998)](https://www.computinghistory.org.uk/det/56643/Creatures%202/), aiming to recreate its learning, genetics, and evolving virtual creatures on a small scale.

> 👷 **Work in progress** — the simulation is experimental and still taking shape.

## Try it

From the project root:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```
